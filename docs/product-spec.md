# FONKON 市场开发系统 1.1 产品规格

## 业务员首页
显示：今日新增客户、有效沟通、CV≥75、OT≥70、PI Top 5、待跟进、红黄绿灯。

## 客户新增
采用分步表单：基本信息 → 进口规模 → 水果/口岸 → 痛点 → 支付意愿 → 决策链 → 项目时间 → 试柜机会 → 证据。

## 客户详情
必须同时展示：
- CV / S-A-B-C-D
- OT
- PI
- AQ：可匹配/可切换/愿意尝试/首批试柜
- 关键痛点
- 证据完整度
- 下一动作

## 访谈模式
根据当前已填写字段动态提示下一问题，目标是帮助新人完成“问/听/记/请教/假设/机会/痛点”的闭环。

## 主管看板
- 业务员客户数量
- S/A/B/C/D分布
- PI Top客户
- AQ Top客户
- 红黄绿灯分布
- 本周新增商机
- 本周试柜机会
- 数据完整度

## 非目标
第一阶段不做复杂财务、订单、船期、报价等模块，避免把市场开发系统做成“大而全”的ERP。
